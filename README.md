## Nintendo Switch Game Library
A modern, responsive web application for managing your Nintendo Switch game collection. Built with React and featuring automatic game artwork fetching from the IGDB API.

## ✨ Features
🎮 Game Collection Management - Add, remove, and organize your Nintendo Switch games

🖼️ Automatic Artwork Fetching - Automatically retrieves high-quality box art from IGDB

🔍 Smart Search - Real-time game search with dropdown selection

📊 Collection Statistics - Track your total games and completion progress

🎯 Completion Tracking - Mark games as completed with a simple toggle

📱 Responsive Design - Beautiful grid layout that works on all devices

🎨 Nintendo-Themed UI - Custom dark theme with Nintendo Switch colors

⚡ Fast & Modern - Built with React and Vite for optimal performance
